HitList

Your tasks, notes and databases, in an app that runs on your own computer. It works without the internet, and nothing is sent anywhere unless you sign in to back up.

Download HitList

Opens the download folder. Take the .dmg for a Mac with Apple silicon (M1 and later), the .exe for Windows 10 and 11, or the .AppImage / .deb for 64-bit Linux. About 200 MB each. Not available for Intel Macs.

Install on a Mac

  1. Open the downloaded HitList-….dmg file.
  2. Drag HitList onto the Applications folder in the window that opens.
  3. Open HitList from Applications. The first time, macOS will stop it. See the next section.

The first time you open it

HitList is not signed with an Apple developer certificate yet, so macOS warns that it can't check the app. That is expected. It is a one-time step.

  1. Try to open HitList. macOS shows a message that it was blocked. Click Done (or OK).
  2. Open System Settings → Privacy & Security and scroll down to Security.
  3. Next to “HitList” was blocked, click Open Anyway, then confirm with your password.
  4. Open HitList again and click Open.
macOS says “HitList is damaged and can’t be opened”, or Open Anyway doesn’t appear

The app is not damaged. macOS words it that way for apps that are not signed with an Apple certificate. Run this once in Terminal, then open HitList normally:

xattr -dr com.apple.quarantine /Applications/HitList.app

It only removes the “downloaded from the internet” mark from this one app.

Install on Windows

  1. Download the HitList-Setup-….exe file and double-click it.
  2. Windows shows a blue “Windows protected your PC” screen, because the app is not signed with a paid certificate. Click More info, then Run anyway.
  3. Follow the installer, then open HitList from the Start menu.

Java is included. The Windows version is new and has not been tested widely, so tell us if anything looks wrong. Your data is kept in %APPDATA%\HitList.

Install on Linux

  1. Download the .AppImage (most distributions) or the .deb (Ubuntu and Debian).
  2. AppImage: make it runnable with chmod +x HitList-*.AppImage, then double-click it or run ./HitList-*.AppImage.
    .deb: run sudo apt install ./HitList_*_amd64.deb, then open HitList from the applications menu. A note starting N: Download is performed unsandboxed as root is harmless; the install worked.
The AppImage doesn’t start

If it mentions FUSE, install it with sudo apt install libfuse2 (on Ubuntu 24.04: libfuse2t64), or run ./HitList-*.AppImage --appimage-extract-and-run instead.

Java is included. The Linux version is new and has not been tested widely, so tell us your distribution and version if anything looks wrong. Your data is kept in ~/.config/HitList.

Using it

  • You don't need an account. HitList works straight away, and your data stays on your Mac.
  • Sign in to back up. Open the account menu (top right) and choose Sign in to back up. Your workspace is then backed up to your account a few times a day, only when something changed.
  • New computer? Install HitList, sign in with the same account, and choose Restore when it offers your backup.

Updating

Download the new version from this page. On a Mac, drag it onto Applications, replacing the old one. On Windows, run the new installer over the old one. On Linux, replace the AppImage or install the new .deb. Your data is kept: it lives in a separate folder, not inside the app.

Where is my data?

On a Mac, in ~/Library/Application Support/HitList; on Windows, in %APPDATA%\HitList; on Linux, in ~/.config/HitList. Deleting or uninstalling the app does not delete it. Don't delete that folder unless you mean to, and use Export workspace in the account menu first if you want a copy.

HitList is the desktop app. The old web version has been retired, so it no longer opens in the browser.
